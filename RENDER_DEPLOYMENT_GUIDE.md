## III. Step-by-Step Deployment 🚀

### Phase 1: Connect to Render
1.  Log in to the [Render Dashboard](https://dashboard.render.com/).
2.  Click **New +** -> **Blueprint**.
3.  Connect your GitHub account and select your **Blood Bank Management System** repository.

### Phase 2: Configuration & Environment Variables
Render will read `render.yaml`. You will need to provide values for the following environment variables:

| Variable Name | Required Value/Action |
| :--- | :--- |
| `DATABASE_URL` | Auto-generated by Render (no action needed). |
| `NODE_ENV` | `production` |
| `NEXTAUTH_URL` | Your public URL (e.g., `https://blood-bank-system.onrender.com`). |
| `AUTH_SECRET` | Run: `openssl rand -base64 32` |
| `NEXTAUTH_SECRET` | Same as `AUTH_SECRET` or another unique string. |
| `ENCRYPTION_KEY` | **CRITICAL**: Exactly 32 characters (e.g., `12345678901234567890123456789012`). |
| `FABRIC_MODE` | `mock` (Required for Render deployment). |

### Phase 3: Deployment
1.  After entering variables, click **Apply**.
2.  **Monitor the Logs**:
    - **Build Phase**: Render installs dependencies (`npm install`), generates the Prisma client (`npx prisma generate`), and builds the Next.js app.
    - **Deploy Phase**: Render runs database migrations (`npx prisma migrate deploy`) and starts the server.

## V. Troubleshooting 🆘

- **Build Failure (TypeScript/next.config.ts)**: If you see an error like `Failed to transpile "next.config.ts"`, ensure `typescript`, `ts-node`, and `@types/*` are in the `dependencies` section of `package.json`.
- **Build Failure (Tailwind/PostCSS)**: If you see `Cannot find module '@tailwindcss/postcss'`, ensure `tailwindcss` and `@tailwindcss/postcss` are in the `dependencies` section (not `devDependencies`). *Note: I have already updated these for you.*
- **Build Failure (Memory)**: If the build fails due to memory, upgrade your Web Service plan from `Free` to `Starter` in `render.yaml`.
- **Database Connection Error**: Ensure `FABRIC_MODE` is set to `mock`.
- **Encryption Key Error**: Ensure `ENCRYPTION_KEY` is precisely 32 characters.
