# Task 16: Blood Bank Staff Dashboard

## Overview
Frontend dashboard for blood bank staff operations.

## Status: `[ ] Not Started`

---

## Features

1. **Donor Registration**
   - Register new donors
   - Search existing donors

2. **Donation Recording**
   - Record new donations
   - Generate unit codes

3. **Test Management**
   - Submit test results
   - View pending tests

4. **Inventory Overview**
   - Stock levels by blood type
   - Low stock alerts
   - Expiring units

5. **Request Management**
   - View pending requests
   - Approve/reject
   - Issue blood units
